# teenbank

## Notes / Changelog

### 2026-10-22

Исправления:
- Исправлены действия главного меню: кнопки "Переказ", "Поповнити", "Скарб" и "Більше" больше не ведут в пустые или нерабочие сценарии.
- Исправлено поведение пополнения баланса: сумма реально добавляется к счету, а баланс обновляется в интерфейсе.
- Исправлены быстрые контакты и действия по переводу денег — теперь они открывают корректный рабочий сценарий.
- Исправлена логика панели навигации, чтобы активная вкладка правильно подсвечивалась и переключалась.
- Убраны тупые/неинформативные состояния, где интерфейс не показывал результат действия пользователю.

Добавлено:
- Добавлено всплывающее меню (bottom sheet) для действий в приложении.
- Добавлены уведомления (toast) после успешных действий, чтобы было понятно, что произошло.
- Добавлено обновление баланса в реальном времени после пополнения.
- Добавлено автоматическое появление новой операции в списке последних транзакций.
- Добавлены более понятные сценарии действий при выборе пунктов в меню.

### План/направление
- Улучшение UX и визуальной логики iPhone-подобного интерфейса.
- Уточнение экранов перевода, пополнения и накоплений.
- Добавление более сложных анимаций и полноценного рабочего состояния приложения.
